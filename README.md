## Приклад написання GET тесту для API
```python
import requests

def test_api_status():
    response = requests.get("https://official-joke-api.appspot.com/jokes/370")
    assert response.status_code == 200
    data = response.json()
    assert data['type'] == 'programming'
```

## Приклад написання POST запита для API
```python
import requests

response = requests.post("https://api.restful-api.dev/objects", 
                         data=
                             {
                                 "name": "Test",
                                 "data": {
                                     "year": 1,
                                     "price": 1,
                                     "CPU model": "test",
                                     "Hard disk size": "test"
                                 }
                             }, 
                         headers={'Content-Type': 'application/json'})
object_id = response.json()["id"]
```

### Структура тесту:
1. Надіслати запит
2. Перевірити статус запиту
3. Якщо перевіряємо дані - кастувати їх у JSON та перевірити самі дані
